# assets_new — 배경 직접 제거한 고화질 버전

여기에 PNG를 올리면 게임이 **`assets/` 보다 먼저** 이 폴더를 씁니다.
(없는 파일은 자동으로 `assets/` → SVG 순서로 대체)

- 파일명은 `assets/`와 동일하게: `fruit0.png` … `fruit6.png`, `bird.png`, `line.png`, `star.png`, `brick1~3.png`
- **투명 배경(진짜 alpha)**, 정사각형
- 화질 유지 위해 여기 올린 건 **리사이즈/재처리 안 함** (원본 그대로 사용)
- 필요한 것만 올려도 됨 (나머지는 기존 assets/ 그대로 사용)
