# 아트 에셋 (PNG)

여기에 PNG를 올리면 게임이 **자동으로** 그 PNG를 씁니다. 파일이 없으면 코드 안의 SVG로 대체돼요.

## 규격
- **정사각형 투명 PNG**, **256~512px** 권장 (작은 칸에서도 선명)
- 오브젝트는 **가운데 정렬, 대략 80% 크기** (사방 여백 ~10%)
- 배경 투명 (바둑판 X)

## 파일 이름 (정확히 지켜주세요)
### 과일
| 파일 | 슬롯/색 |
|---|---|
| `fruit0.png` | 체리 (빨강) |
| `fruit1.png` | 오렌지 (주황) |
| `fruit2.png` | 키위 (초록) |
| `fruit3.png` | 레몬 (노랑) |
| `fruit4.png` | 포도 (보라) |
| `fruit5.png` | 배 (연녹) |
| `fruit6.png` | 바나나 (파랑) |

### 아이템 / 벽돌
| 파일 | 설명 |
|---|---|
| `bird.png` | 참새 — **왼쪽을 보게** (오른쪽 이동 시 자동 반전) |
| `line.png` | 라인 — **가로 방향** (세로는 자동 90° 회전) |
| `star.png` | 별 |
| `bomb.png` | (선택) 폭탄 아이콘 — 없으면 "과일+심지"로 자동 처리 |
| `brick1.png` | 벽돌 HP1 (부서지기 직전) |
| `brick2.png` | 벽돌 HP2 (파손) |
| `brick3.png` | 벽돌 HP3 (온전) |

## 올리는 법
GitHub 저장소 → `assets/` 폴더 → **Add file → Upload files** 로 드래그해서 커밋하면 끝.
1~2분 뒤 게임 새로고침하면 반영돼요.
