## AI 이미지 프롬프트 사용법

아래 표의 프롬프트 칸은 **그대로 한 번만 복사**하면 되는 완성된 프롬프트입니다.
주제 → 색 지시 → 스타일이 이미 하나로 합쳐져 있으니 **접미사를 따로 붙이지 마세요.**

대부분의 유물은 물건이라 얼굴이 있으면 안 되므로 "눈·코·입을 그리지 말라"가 자동으로 붙습니다.
얼굴이 주제인 것들(`_style.with_face`: flock, piggy_cherry, rich_eye, trait_feed, trait_keen_eye, trait_nest_egg, trait_sharp_eye, trance)만 예외입니다.

아래 두 블록은 무엇이 붙는지 확인용입니다 — 복사할 필요 없습니다.

**유물용 접미사**

```
cute cartoon mobile game icon, thick dark navy outline, glossy 2.5D cel-shading, soft specular highlights, bold simple silhouette, one single centred object, isolated on a plain flat pure white background, no shadow, no gradient, no text, no checkerboard, square 1:1
```

**특성용 접미사** (특성은 물건이 아니라 휘장으로 통일)

```
cute cartoon emblem badge icon, thick dark navy outline, glossy 2.5D cel-shading, soft inner glow, bold simple silhouette, one single centred emblem, isolated on a plain flat pure white background, no shadow, no gradient, no text, no checkerboard, square 1:1
```

> 표의 프롬프트 칸은 **그대로 한 번만 복사**하면 되는 완성된 프롬프트입니다. 주제 → 색 지시 → 스타일 순서로 이미 합쳐져 있으니 접미사를 따로 붙이지 마세요. 아래 접미사 블록은 무엇이 붙는지 확인용입니다. 바나나는 파랑(#00b4d8), 키위는 초록(#43d17a), 복숭아는 연한 산호색(#ffab8f)이라 생성기가 기본값으로 그리면 틀립니다. _style.colors 는 게임의 COLORS 와 반드시 같아야 하며, 다르면 gen-catalog.py 가 거부합니다.

### 투명 배경은 프롬프트로 안 됩니다

이미지 생성 모델은 알파 채널을 만들지 못합니다. 'transparent background'라고 쓰면 투명을 표현하는 체크무늬를 그림으로 그려버리므로, 대신 **단색 흰 배경**을 요구하고 받은 뒤에 `python3 tools/cutout.py 원본.png 결과.png` 로 배경을 지우세요. 주제가 대부분 흰색이면(설탕·클로버 등) 배경을 `flat solid magenta background`로 바꾸고 `--bg FF00FF` 를 주면 됩니다.

```
python3 tools/cutout.py 받은이미지.png assets_new/relic_개간.png
```
